トランスパイラー / 翻訳マッピング
===

# 概要

* 翻訳マッピングの使用方法に関して記載

# 役割

* 変換元のモジュールパスと、変換先のクラス・関数・変数名をマッピング

# 使用方法

## データ定義

* ドメイン毎のエイリアスと、モジュールの定義がセット

```yaml
# エイリアス
aliases.myapp: aliases.myapp
# モジュール
aliases.myapp.module.path.to.A#A: A2
aliases.myapp.module.path.to.A#B: B2
```

## テンプレート実装

* `i18n`ヘルパーを通して使用
* 第1引数: エイリアス
* 第2引数: モジュールパス

```jinja2
{{ i18n('myapp', 'module.path.to.A#A') }}
```

## トランスパイル

```python
# module.path.to.A
class A: ...
a = A()
```
↓
```cpp
class A2 {};
A2 a{};
```
