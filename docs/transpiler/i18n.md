トランスパイラー / 翻訳マッピング
===

# 概要

* YAMLで定義
* 変換元のモジュールパスから、変換先のクラス・関数・変数名への変換テーブルを管理

# 使用方法

## データ定義

* ドメイン毎のエイリアスと、モジュールの定義がセット

```yaml
# エイリアス
# 書式: alias.{identifier}
aliases.myapp: aliases.myapp
# モジュール
# 書式: alias.{identifier}.{module_path}#{qualified_name}
aliases.myapp.module.path.to.A#A: A2
aliases.myapp.module.path.to.A#B: B2
```

## テンプレート実装

* `i18n`ヘルパーを通して使用
* 第1引数: エイリアス
* 第2引数: モジュールパス

```jinja2
{{ i18n('myapp', 'module.path.to.A#A') }}
```

## トランスパイル

```python
# module.path.to.A
class A: ...
a = A()
```
↓
```cpp
class A2 {};
A2 a{};
```
