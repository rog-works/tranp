トランスパイラー / 翻訳マッピング
===

# 概要

* 翻訳マッピングの使用方法に関して記載

# 使用方法

## 定義

```yaml
# エイリアス
aliases.myapp: aliases.myapp
# モジュール
aliases.myapp.module.path.to.A: A2
```

## テンプレート

* `i18n`ヘルパーを通して使用
* 第1引数: エイリアス
* 第2引数: モジュールパス

```jinja2
{{ i18n('myapp', 'module.path.to.A') }}
```

## トランスパイル

```python
# Python
A
```
↓
```cpp
// C++
A2
```
